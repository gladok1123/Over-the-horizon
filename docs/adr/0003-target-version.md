# ADR 0003: Целевая версия — кастомный MVP

## Context
Полная совместимость с конкретной версией MC (1.20.1/1.21.x) требует 1:1 datapack/протокольных форматов и увеличивает scope.

## Decision
**Кастомный MVP без жёсткой привязки к версии** (выбор пользователя). JSON-форматы держать близкими к MC для datapack-совместимости, но без гарантии 1:1.

## Consequences
- Плюс: меньше scope, быстрее MVP.
- Минус: нельзя обещать совместимость с реальными datapack/ресурспаками конкретных версий.
