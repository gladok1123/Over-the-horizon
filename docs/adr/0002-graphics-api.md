# ADR 0002: Графика — Silk.NET

## Context
Нужен кроссплатформенный графический API (Windows/Linux/macOS) с OpenGL 4.6 + Vulkan, без рефлексии, AOT-friendly.

## Decision
**Silk.NET** (выбор пользователя). Клиент — позже (сервер-first), но абстракция закладывается сразу.

## Consequences
- Плюс: low-level контроль, активно поддерживается, нет рефлексии.
- Минус: ниже уровень абстракции, чем Veldrid; больше ручной работы на мешинг/шейдеры.
