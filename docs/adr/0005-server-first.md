# ADR 0005: Приоритет — сервер в первую очередь

## Context
Нужен порядок разработки: сервер (dedicated + headless) vs клиент (графика/UI).

## Decision
**Сервер в первую очередь** (выбор пользователя). Клиент (Silk.NET) — после MVP сервера.

## Consequences
- Плюс: headless-тесты и тесты детерминизма дают объективный критерий качества без графики.
- Минус: визуальная проверка откладывается; митигация — хеши мира + интеграционные тесты.
