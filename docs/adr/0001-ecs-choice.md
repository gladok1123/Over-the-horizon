# ADR 0001: ECS — Arch

## Context
Нужен ECS для сущностей и block entities с параллельным AI-тикoм, детерминированной итерацией и AOT-готовностью сервера.

## Decision
Использовать **Arch** (выбор пользователя). Компоненты: `Position`, `Velocity`, `Health`, `AI`, `Render`, `Inventory` и т.д. Параллельный AI-тик по read-only snapshot; мутации применяются детерминированно в Phase 4.

## Consequences
- Плюс: зрелая библиотека, быстрый старт.
- Минус: внешняя зависимость; проверить AOT-совместимость и детерминированный порядок итерации на Шаге 3.
- Альтернативы (собственная SoA, DefaultEcs) отклонены по выбору пользователя; пересмотр — только если Arch не пройдёт AOT/детерминизм-тесты.
