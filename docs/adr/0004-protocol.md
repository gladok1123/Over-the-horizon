# ADR 0004: Протокол — Java + Bedrock (фазово)

## Context
Пользователь выбрал совместимость с обоими протоколами. Это значительно расширяет scope (два кодека).

## Decision
**Java + Bedrock, фазово** (выбор пользователя):
- Фаза 1 (MVP): Java-ядро + кастомный внутренний протокол.
- Фаза 2 (Beta): Bedrock-кодек + тесты/fuzz.

## Consequences
- Плюс: шире совместимость.
- Минус: двойной объём кодеков/тестов; риск scope creep. Митигация — общий слой абстракции пакетов, Bedrock только после стабильности Java-ядра.
