# Как запустить и поиграть с друзьями (`v0.1.0-alpha`)

В релизе **Over-the-Horizon `v0.1.0-alpha`** готовы самодостаточные сборки клиента и выделенного сервера для **Windows (`win-x64`)**, **Linux (`linux-x64`)** и **macOS (`osx-arm64`, `osx-x64`)**. Вашим друзьям **не нужно** устанавливать `.NET SDK`, OpenAL или GLFW — всё уже упаковано внутри архива.

---

## Вариант 1 (Самый быстрый — для вас и друзей без установки .NET)

1. Перейдите в раздел **[GitHub Releases (`v0.1.0-alpha`)](https://github.com/gladok1123/Over-the-horizon/releases/tag/v0.1.0-alpha)** репозитория (или скачайте артефакт `OverHorizon-v0.1.0-alpha-playable-builds` из последнего запуска GitHub Actions).
2. Скачайте архив под вашу ОС:
   - Windows 10/11: `OverHorizon-v0.1.0-alpha-win-x64.zip`
   - Linux x64: `OverHorizon-v0.1.0-alpha-linux-x64.zip`
   - macOS (Apple Silicon M1/M2/M3/M4): `OverHorizon-v0.1.0-alpha-osx-arm64.zip`
   - macOS (Intel): `OverHorizon-v0.1.0-alpha-osx-x64.zip`
3. Распакуйте архив в любую папку.

### Кто создаёт сервер (Хост)
1. Запустите **`Start-Server.bat`** (Windows) или **`./start-server.sh`** (Linux/macOS).
   - Сервер поднимется на TCP-порту **`25565`**, создаст папку `./world` для автоматического сохранения карты (каждые 30 секунд + при нажатии `Ctrl+C`) и выведет ваш локальный IPv4-адрес.
   - Если защитник/брандмауэр Windows спросит доступ к сети — нажмите **«Разрешить доступ»**.
2. Чтобы самому зайти на свой сервер, запустите **`Join-Friend-Server.bat`** (не закрывая окно сервера!), нажмите `Enter` на запросе адреса (`127.0.0.1:25565`) и введите свой никнейм (латиницей до 16 символов, например `HostAlex`).

### Как друзьям подключиться через Интернет (3 удобных способа)

- **Способ А — Radmin VPN / Tailscale / ZeroTier (рекомендуется, без настройки роутера)**:
  1. Хост и друзья заходят в одну виртуальную сеть в **Radmin VPN** или **Tailscale**.
  2. Друзья копируют виртуальный IPv4-адрес хоста (например `26.45.12.88`).
  3. Друзья запускают **`Join-Friend-Server.bat`**, вводят `26.45.12.88:25565` и свой уникальный никнейм (`FriendMax`).

- **Способ Б — Playit.gg (друзьям вообще ничего не нужно ставить!)**:
  1. Хост запускает бесплатный туннель **[playit.gg](https://playit.gg)** и создаёт *Custom TCP Tunnel* → `127.0.0.1:25565`.
  2. Playit выдаст публичный адрес вида `example.gl.at.ply.gg:49152`.
  3. Друзья вводят этот адрес в **`Join-Friend-Server.bat`** и сразу попадают в ваш мир!

- **Способ В — Одна Wi-Fi / LAN сеть или белый IP (проброс TCP порта `25565`)**:
  - В локальной сети друзья вводят локальный IP хоста из консоли сервера (например `192.168.1.42:25565`).

## Вариант 2 (Запуск напрямую из исходного кода через `.NET 9 SDK`)

```bash
# Терминал 1 — Выделенный сервер с сохранением мира в ./world
dotnet run --project src/OverHorizon.Server/OverHorizon.Server.csproj -c Release -- \
  --port 25565 --view-distance 4 --seed 2026 --world-dir ./world --op-all

# Терминал 2 — Игрок 1
dotnet run --project src/OverHorizon.Client/OverHorizon.Client.csproj -c Release -- \
  --connect 127.0.0.1:25565 --username Alex --view-distance 4

# Терминал 3 (или ПК друга) — Игрок 2
dotnet run --project src/OverHorizon.Client/OverHorizon.Client.csproj -c Release -- \
  --connect <IP_ХОСТА>:25565 --username Max --view-distance 4
```

## Управление в игре

| Клавиша / Действие | Назначение |
| --- | --- |
| **`W` / `A` / `S` / `D`** | Перемещение по миру |
| **`Left Shift` / `Left Ctrl`** | Бег (спринт) |
| **`Space` (Пробел)** | Прыжок |
| **Движение мыши** | Поворот камеры |
| **Левая кнопка мыши (ЛКМ)** | Сломать подсвеченный блок (дистанция до 6 блоков, 3D DDA Raycast) |
| **Правая кнопка мыши (ПКМ)** | Поставить выбранный блок на грань подсвеченного блока |
| **Клавиши `1`..`9` / Колесо мыши** | Выбор строительного блока в 9-слотовом хотбаре внизу экрана |
| **`F3`** | Показать в заголовке окна FPS, координаты `(X, Y, Z)`, активный блок и число друзей онлайн |
| **`Esc`** | Освободить / вернуть захват курсора мыши |

### Слоты строительного хотбара (`1`..`9`)
1. **Булыжник** (`cobblestone`)
2. **Камень** (`stone`)
3. **Земля** (`dirt`)
4. **Дёрн** (`grass_block`)
5. **Дубовые доски** (`oak_planks`)
6. **Дубовое бревно** (`oak_log`)
7. **Песок** (`sand`)
8. **Дубовая листва** (`oak_leaves`)
9. **Светящийся камень** (`glowstone` — излучает свет уровня 15!)
